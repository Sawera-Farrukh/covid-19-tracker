# 🦠 COVID-19 Tracker

A clean and modern **Flutter** application that displays live COVID-19 statistics for the entire world as well as individual countries.
The app fetches real-time data from a public API, converts the JSON response into structured Dart models, and presents the information 
through a smooth and user-friendly interface. Users can view global totals (cases, recovered, deaths, active, and critical), 
explore data visually with a pie chart, and quickly search any country to see its complete statistics along with its flag — all wrapped
in a clean dark theme.

## ✨ Features

- 🌍 **Global Overview** – Total cases, recovered, deaths, active & critical
- 📊 **Interactive Pie Chart** – Easy visual understanding of the data
- 🔍 **Country Search** – Quickly find and view any country’s full statistics
- 🏳️ **Country Flags** – Beautiful flag icons for every country
- 🌑 **Dark Theme** – Modern and eye-comfortable dark UI
- 🔄 **Live Data** – Real-time data fetched from a public API
